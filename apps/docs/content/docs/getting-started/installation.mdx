Download the latest release of Omniscribe for your platform from [GitHub Releases](https://github.com/Shironex/omniscribe/releases/latest).

## System Requirements

| Platform | Minimum Version | Architecture  |
| -------- | --------------- | ------------- |
| macOS    | 10.15 Catalina  | Apple Silicon |
| Windows  | 10              | 64-bit        |

## Download & Install

<Tabs items={["macOS", "Windows"]}>
<Tab value="macOS">

1. Download the `.dmg` file from the [latest release](https://github.com/Shironex/omniscribe/releases/latest)
2. Open the `.dmg` and drag **Omniscribe** into your Applications folder
3. On first launch, right-click the app and select **Open** (macOS blocks unsigned apps by default)

<Callout title="Apple Silicon only">
  macOS builds currently target Apple Silicon (M1/M2/M3/M4). Intel Mac support is not available at
  this time.
</Callout>

</Tab>
<Tab value="Windows">

1. Download the `.exe` installer from the [latest release](https://github.com/Shironex/omniscribe/releases/latest)
2. Run the NSIS installer — you can choose a custom install directory during setup
3. Launch Omniscribe from the Start Menu or desktop shortcut

</Tab>
</Tabs>

## All Versions

Browse all releases, including older versions and changelogs, on the [GitHub Releases page](https://github.com/Shironex/omniscribe/releases).

## Beta Releases

Omniscribe supports automatic updates. To opt in to beta (pre-release) builds, go to **Settings > General > Updates** and enable the beta channel. You will receive pre-release updates alongside stable ones.

<Callout title="Tip">
  You can always switch back to the stable channel from the same settings page.
</Callout>
