Here is what to expect when you open Omniscribe for the first time.

## Splash Screen

A brief splash screen with the Omniscribe logo appears while the app initializes. This takes a few seconds on first launch.

## Welcome View

After initialization, you land on the welcome view. It shows your recent projects (empty on first launch). Click the open button to browse for a project folder.

## UI Orientation

Once a project is open, the main interface has three areas:

- **Top bar** -- Project tabs, session actions, and the settings button
- **Session grid** -- The central area where your AI sessions live
- **Pre-launch slots** -- Cards that appear before sessions are started, one per slot

## Pre-launch Slots

Each slot lets you configure a session before launching it:

- **AI mode selector** -- Choose between Claude Code, Codex, or Plain terminal (only installed providers appear)
- **Branch selector** -- Pick a branch to work on (available when git worktrees are enabled)
- **Launch button** -- Start the session, with a shortcut key displayed on the button

## Keyboard Shortcuts

A few shortcuts to get you moving quickly:

| Shortcut  | Action                   |
| --------- | ------------------------ |
| `N`       | Add a new session slot   |
| `Shift+N` | Add a slot from presets  |
| `L`       | Launch all pending slots |
