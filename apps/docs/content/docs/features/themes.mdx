Omniscribe ships with 41 UI themes and 12 terminal color themes, so you can match the app to your preferred look. Themes are applied instantly via CSS custom properties -- no reload required.

## Terminal Themes

Terminal color themes are independent of the UI theme. This lets you pair any UI look with your preferred terminal palette.

Change the terminal theme in **Settings > Terminal**.

**Available terminal themes (12):**

|          |            |              |
| -------- | ---------- | ------------ |
| midnight | tokyonight | dark         |
| light    | dracula    | nord         |
| monokai  | gruvbox    | catppuccin   |
| onedark  | solarized  | github-light |

The default terminal theme is **tokyonight**.

## Per-Project Persistence

Each project tab remembers its own theme selection. If you prefer a dark theme for backend work and a light theme for documentation, Omniscribe keeps each project tab styled independently.

## Splash Screen

The splash screen that appears on startup follows the currently active theme colors, so the app feels consistent from the moment it opens.
